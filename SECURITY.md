# Security policy

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting instead:

1. Go to the **Security** tab of this repository.
2. Choose **Report a vulnerability**.
3. Describe what you found and how to reproduce it.

Only the maintainer can see the report. You will get a first reply within about seven days. Fixes are made in private and credited to you in the release notes if you want that.

## Supported versions

Only the latest release gets fixes.

## Scope

- A report about the mod's scripts (`Scripts/`) that could run code on another player's machine.
- Anything that leaks a token, path or private server detail through the mod or its logs.
- Not in scope: bugs in Space Engineers 2 itself, Pulsar or LinuxCompat. Report those to their projects.
